Avaya NOC — easy install (ZIP → IIS → Login)
============================================

Your goal (supported):
  1. Install IIS yourself (Windows Features)
  2. Extract this package to a folder (example: C:\inetpub\wwwroot\CM)
  3. Run ONE script as Administrator:

       powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1

  4. When asked, confirm ROOT path (default = this package folder)
  5. Open the URL printed (e.g. http://127.0.0.1:8888/)
  6. Enter CM Host + Password → Login → monitoring starts

What install.ps1 does:
  - Detects IIS (if missing, tells you to install IIS first — does NOT auto-install IIS)
  - Checks / installs .NET 8 Hosting Bundle if missing (winget or download)
  - Checks / installs Python 3.12 if missing (winget or python.org, with PATH)
  - Asks LOCAL ROOT path
  - Points IIS site + /api to that path
  - Creates Python venv + installs bundled avaya-ossi (vendor\)
  - Writes appsettings for that path
  - Registers OSSI bridge auto-start at Windows logon
  - Starts bridge once

You do NOT need a separate OSSI repo clone.
You do NOT need to start the bridge manually every day.

Requirements:
  - Windows IIS (user installs)
  - Admin rights for install.ps1
  - Internet access the first time (to download Hosting Bundle / Python if missing)

Optional flags:
  -SkipDotNetInstall   do not auto-install Hosting Bundle
  -SkipPythonInstall   do not auto-install Python
  -SkipUpdate          do not git pull (freeze code on disk)
  -NonInteractive -RootPath "C:\path" -SitePort 8888

------------------------------------------------------------
ONE command for new install AND upgrade (auto-detect)
------------------------------------------------------------
Always the same:

  cd C:\inetpub\wwwroot\CM\scripts
  powershell -ExecutionPolicy Bypass -File .\install.ps1

Script detects:
  - git clone?  -> auto git pull from GitHub
  - existing api/venv/data?  -> full upgrade path
  - keeps data\monitored_trunks.json
  - republish api, rewire IIS, restart bridge

No need for -Update flag.

ZIP-only (no .git): re-run install.ps1 after replacing files,
or convert to git clone once for auto pull next time.
